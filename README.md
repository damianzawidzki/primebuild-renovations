## Project Overview

PrimeBuild Renovations is a responsive business website created using HTML, CSS and JavaScript.

The website presents renovation services, completed projects, company information and contact details through a professional multi-page layout.

## Features

- Responsive desktop, tablet and mobile design
- Professional navigation bar
- Mobile navigation menu
- Full-screen hero section
- Renovation service cards
- Completed projects gallery
- Dedicated About Us page
- Why Choose Us section
- Dedicated Contact page
- Responsive quotation form
- FormSubmit email integration
- Reusable JavaScript footer
- Smooth scrolling
- Interactive hover effects
- Semantic HTML structure
- Accessible form labels

## Running the Project Locally

Clone the repository:

```bash
git clone https://github.com/damianzawidzki/primebuild-renovations.git
```

Open the project folder:

```bash
cd primebuild-renovations
```

Start a local server:

```bash
py -m http.server 5500
```

Open the website:

```text
http://localhost:5500/index.html
```

## Responsive Design

The website adapts to:

- Desktop computers
- Laptops
- Tablets
- Mobile phones

On smaller screens, the navigation changes into a collapsible mobile menu and the content uses single-column layouts.

## Contact Form

The quotation form uses FormSubmit to deliver enquiries directly to the configured email address without requiring a custom backend server.
